Map overlays for WEFAX charts

Each .png file here appears under Overlay, above the chart in the WEFAX panel. Add your own beside
northwood_land_overlay.png, which is an example, and they'll be listed the next time you open the list.

An overlay is a picture with a transparent background: the land, say, with everything else see-through.
Make one by tracing a whole chart of one product, such as one station's surface analysis, since the same
product always covers the same area. It can be any size. It's scaled to the chart's width, with its top
left corner on the chart's, so draw it over the whole chart, margins included.

X and Y move it, for a chart that was tuned in late. Save a copy puts the chart with its overlay in the
received folder as a new PNG. The chart itself is never changed.
