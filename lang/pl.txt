= Automatycznie oznacza język ustawiony w komputerze. Wybierz język, aby go używać niezależnie od ustawień komputera. Zmiana działa od razu.

Check GitHub for a new version at start
= Sprawdzaj na GitHub nową wersję przy starcie

Reads one small file from GitHub each time the program starts, and says on the bottom line if there's a newer build. Nothing about you or your radio is sent.
= Przy każdym starcie programu pobiera jeden mały plik z GitHub i informuje w dolnym wierszu o nowszej wersji. Nie są wysyłane żadne dane o Tobie ani o radiu.

= Włącza radio przy starcie programu i wyłącza przy jego zamknięciu. Aby radio się wybudziło, jego USB musi pozostać zasilane.
